# ios/

The native iPhone shell. It hosts the bundled web UI in a WKWebView and owns what the
web can't: keyboard geometry, the Face ID-locked device token, the mark's edit menu,
haptics, lifecycle and media. Spec: [ios-shell.md](../docs/design/ios-shell.md).
Mechanism the code doesn't show, and how to install on the phone:
[.context/CONTEXT.md](.context/CONTEXT.md).

- **The page owns the keyboard.** Typing goes to the web's own text boxes, as in phone
  Safari. Native has no text field and no focus controller, and must not take first
  responder from WebKit; it only measures the keyboard and reports it in `viewport`.
  A new input feature is web code.
- **Add server is native.** A `muxen://add` link prefills host and optional code but
  never enrols until Next and Add are tapped.
- **The bridge contract has one copy:** the fixtures in
  `MuxenKit/Tests/Fixtures/bridge/`. The Swift DTOs and `web/platform/native/` both
  decode them, so a message change edits all three in one commit.
- **A native request to a daemon goes through `MuxenAppModel.request(on:path:query:)`**,
  which adds the host's `baseURL` and Bearer token and follows redirects only through
  `HostRequest.redirect`, so a token never follows a redirect to another host. Don't
  look up a host's URL or token yourself.
- **AVFoundation never holds a token.** `Media/MediaLoader.swift` fetches through
  `request(on:path:)`; don't pass auth headers to an `AVURLAsset`.
- **Every native screen over the page goes up through `MediaController.show`.** A
  `present` called elsewhere can be dropped by UIKit or stay over the lock screen.
- **`project.yml` is the project.** `Muxen.xcodeproj` is generated by XcodeGen and
  ignored; never hand-edit `project.pbxproj`. The signing team stays out of the repo.
- **Builds and tests run on the Mac:** `ios/scripts/check.sh`. Preflight doesn't build
  iOS.
- **The Simulator can't verify input.** It shows no software keyboard from an agent
  shell, and `simctl` can't tap or type. Keyboard, focus, geometry and rotation are
  verified only by the device checklist in ios-shell.md, which Jimmy runs on his
  iPhone; report a change to any of them as Simulator-built and device-unverified.
